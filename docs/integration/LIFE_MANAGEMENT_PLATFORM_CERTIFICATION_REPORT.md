# SECTION 3 — Cross-Platform Execution Workflows

```text
  [Universal Capture / User Action]
                ↓
  [Dio Client (ApiClient + AuthInterceptor)]
                ↓
  [Spring Boot REST Controller & Service Layer]
                ↓
  [PostgreSQL 16 Database + pgvector Vector Storage]
                ↓
  [AI Companion Context Vector Graph (142+ Nodes Synced)]
                ↓
  [Global Cmd+K Search Index & Riverpod State Refresh]
```

- **Workflow 1 (Goal -> Tasks -> Calendar -> AI Context)**: Creating a goal automatically generates actionable priority tasks, populates due dates on the calendar timeline, and indexes into vector memory graph. `[PASS]`
- **Workflow 2 (Habit Completed -> Health -> Analytics -> Timeline)**: Logging workouts or habit completions updates health streak indicators, recalculates wellness analytics, and records a timeline log. `[PASS]`
- **Workflow 3 (Expense Logged -> Finance -> Budget -> AI Context)**: Entering an expense adjusts account balances, calculates remaining budget, and enables AI Companion safe spending recommendations. `[PASS]`
