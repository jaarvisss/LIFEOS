# SECTION 2 — Executive Summary & Nervous System Architecture

The **LifeOS Communication Platform** operates as the real-time event distribution backbone. It routes notifications and reminders generated across all 18 Bounded Contexts (Task deadlines, Calendar events, Health vitals, Finance alerts, Relationship birthdays, AI recommendations) through quiet hours preferences and delivery log tracking.

```text
  [Platform Event Trigger: Task / Calendar / Health / Relationship / AI]
                                  ↓
  [Notification Service & User Quiet Hours Preference Evaluation]
                                  ↓
  [Spring Boot REST Controller & PostgreSQL delivery_logs Persistence]
                                  ↓
  [Dio Client API Sync & Notifications Modal / Bell Badge Refresh]
```
